# Security Policy

This repository is maintained by a small team. Vulnerability reports are handled on a best-effort basis with responsible disclosure.

## Supported Versions

- `main`: supported
- historical tags/releases: best effort only

## Reporting a Vulnerability

Do not open public issues for potential security vulnerabilities.

Preferred channels:

1. GitHub Security Advisory (private)
2. Private maintainer contact listed in `.github/CODEOWNERS`

Include the following details:

- affected component/file
- reproduction steps or proof of concept
- expected security impact
- suggested mitigation (if available)

## Response Expectations

- acknowledgment: within 3 business days
- triage decision: within 7 business days
- high/critical fixes: target 14-30 days (best effort)

Timelines may vary based on team availability.

## Disclosure Process

1. private report received
2. severity triage
3. remediation implemented and validated
4. patch/advisory published
